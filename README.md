I Go to the official Git website: https://git-scm.com/.

Step 2: How I Install Git
Once the download is complete, open the Git installer file (Git-x.y.z.exe).
The installation wizard will open. Follow these steps:
I Select components you wish to install (usually, the default options are fine).
Click Install to begin the installation process.

Once installed, I open Git Bash or Git CMD from the Start menu to use Git.

Step 3: How I Configure Git
After installing Git, i set up my identity for Git commits. I Open a terminal on Git Bash and enter the following commands to set your name and email address:

Step 4: Verify the Installation

I Type the following command to verify if my Git is installed:
